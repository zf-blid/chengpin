怎么组织脑图？（点击展开规范）
中心主题 = 剧本名。它的下一级 = 事件；事件的下一级 = 选项。
另有五个可选小节：# 阶段 # 轨道 # 随机事件池 # 特殊事件 # 结局。
数值是 8 维：学业 / 人际 / 心态 / 资源 / 金钱 / 技能 / 体魄 / 声望。
事件：社团招新 | year=大一·秋, stage=2, days=40, onlyCollege=计算机学院, settle=true, desc=案发现场
选项（分叉点用 lane 选路线）：加入辩论队 | d=一周两次, x=学业+8 技能+3, need=人际>40 声望>10, fallback=true, o=结果语
特殊事件的触发条件写 when=心态<20；结局写 tier=顶级结局, when=学业>90&&资源>70。
结尾也可直接贴缩进大纲 / Markdown（见「导出大纲」的格式）。
